# Supertext Translation for HubSpot

Translate your HubSpot content with [Supertext](https://www.supertext.com) AI: website pages, landing pages, blog posts, marketing emails and knowledge base articles. Each language becomes its own version in HubSpot, saved as a draft for you to review and publish. Pages and blog posts become HubSpot language variants of the original (one multi-language group); emails get one copy per language; articles a linked translation.

> **Status: tested on a real HubSpot account** (17 October 2026: installing with OAuth, blog posts into language variants). Not yet in the HubSpot App Marketplace. What has been confirmed on a real account and what is still to check (pages, emails, knowledge base) is in [Known limitations](docs/DEVELOPER.md#known-limitations--roadmap).

![Translate with Supertext: the website page About us selected, Swiss French and Swiss High German ticked](docs/images/translate-page.png)

- **Hosted app** (Node.js on Railway), installed in HubSpot with OAuth. Nothing to install on your website.
- **Five kinds of content:** website pages, landing pages, blog posts, marketing emails and (with Service Hub Professional or Enterprise) knowledge base articles.
- **Drafts only:** nothing is published or sent; the original is never changed.
- Translates titles, meta descriptions, subject lines, preview text, rich text and the text fields of modules; keeps layout, images, links, forms and **HubL / personalization tokens** (`{{ contact.firstname }}`).
- Existing language versions get a fresh translation of their drafts; untick *Update existing versions* to keep them.
- **Translation files:** *Export for translation* as XLIFF 1.2 (for translation tools) or HTML, and *Import translation* of the translated file, with a summary of what was imported.
- The app's pages are in English, German, French and Italian.

**Needs:** a HubSpot account with Content Hub or Marketing Hub (Professional or Enterprise for multi-language content) and a Supertext account with an API key. No Supertext account yet? [Create one at supertext.com](https://www.supertext.com/person/en/account/signin). Generate your API key at [supertext.com → Integrations → API](https://www.supertext.com/en/integrations/api) (requires the Admin role).

## Export for translation and import (XLIFF and HTML)

Besides translating with Supertext AI, you can export a page, blog post, email or article as a file, have it translated elsewhere and import the result.

- **Where:** *Export for translation* on the Translate page and the *Import translation* page in the top bar.
- **Formats:** XLIFF 1.2 for translation tools such as Trados, memoQ or Phrase (formatting travels as protected tags; several target languages in one file), or HTML (one language per file) for translators or Supertext's web app, which keeps the file's head and `data-st-id` attributes, so the translated file imports as it is.
- **Import:** the file says what it was exported from and for which language. The translations are written with the same rules as a Supertext AI translation, and a summary shows what was imported and what was skipped: source changed since the export (import those anyway with *Also import texts whose source changed since the export*), not translated, formatting changed, not in the file.
- **Safe:** files over 10 MB, files from another system and translations that add markup the source doesn't have are refused; uploaded files aren't stored.
